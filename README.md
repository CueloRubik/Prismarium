# Prismarium

**Prismarium** es un juego de acción RPG 2D desarrollado en **LÖVE (Love2D)**. Explora mapas, enfrenta enemigos y jefes, colecciona cartas de vehículos y personaliza tu equipamiento en el laboratorio.

## Ejecutar

Instala LÖVE 11.4 o superior y abre el archivo `Prismarium.love` o ejecuta `love .` desde la raíz del proyecto.

## Contenido del repositorio

- Código fuente Lua en la raíz.
- `assets/`: fondos, sprites de vehículos y enemigos, UI, cartas, sonidos y tipografía.
- `tests/`: comprobaciones automatizadas disponibles.
- `docs/`: notas de desarrollo.

## Controles

- Ratón: movimiento y orientación.
- Clic izquierdo / S: onda prismática.
- Clic derecho / Espacio: dash.
- 1, 2, 3: habilidades secundarias equipadas.
- ESC: pausa.
