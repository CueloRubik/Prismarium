# Prismarium

Prismarium es un juego de acción RPG 2D realizado en LÖVE (Love2D). Incluye mapas, combates, jefes, cartas de vehículos, skins y un laboratorio.

## Ejecutar

Instala LÖVE 11.4 o posterior y abre el archivo `Prismarium.love` o ejecuta `love .` dentro del directorio del juego.

## Controles

- Ratón: movimiento y orientación.
- Clic izquierdo o S: onda prismática.
- Clic derecho o Espacio: dash.
- 1, 2, 3: habilidades secundarias equipadas.
- ESC: pausa.

## Contenido

El código Lua, las imágenes PNG, los fondos, la fuente RPG y las pruebas forman parte del proyecto.

**Estado:** proyecto en desarrollo; todavía pueden existir fallos de juego o de presentación.
